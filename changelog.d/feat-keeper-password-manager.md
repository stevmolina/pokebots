### Added

- Connect Keeper from Marketplace › Apps › Keeper. Sign in with your Keeper email and master password,
  enter a two-step code or approve the device when Keeper asks, and agents can sign in to sites with
  the logins in the Keeper folder "Shared with OpenBot". The browser fills the password and the
  one-time code; the agent never sees them. OpenBot installs Keeper Commander, Keeper's official CLI,
  the first time you connect. On a joined server, the server must also run this version.
