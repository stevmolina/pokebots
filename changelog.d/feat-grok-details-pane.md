### Changed

- The agent details pane now matches the chat background, uses a 459 px default width, and removes
  the top tab bar when only the agent pane is open.
- A centered 64 px avatar, the agent name and role, and `Activity | Library` tabs sit at the top
  with a round close button.
- The `Activity` tab shows Sessions, Routines with inline switches, Model, Pinned messages,
  Notifications, and Tools (`Browser`, `Files`, and resize) in grouped cards.
- The `Library` tab shows Files, Memories, and Tables together with filter chips and dated file
  cards.
- When you open `Browser` or `Files` beside the agent pane, the side-panel tab bar returns.
