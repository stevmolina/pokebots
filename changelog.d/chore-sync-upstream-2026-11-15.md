### Changed

- Pokebots now includes every OpenBot change through version 0.71.0 and 117 later commits, up to upstream commit `dfb9d8147`.
- HTML visual replies in agent threads now use OpenBot's own visual reply card. A page in a thread writes and quotes in that thread's message box.
- A server shows the plush look that an owner or admin chose for it. A server with no chosen look keeps its Pokebots machine mark.
