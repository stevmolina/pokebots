### Added

- Agents on a server can now listen to Rooms all day. Turn it on for an agent in Server Settings > Agents > Rooms listening. When someone writes in one of your Rooms, the server starts a turn for that agent, and the agent answers with its Rooms tools. A paused room gets no turn, Stop on the room page turns listening off, an agent gets at most 20 Rooms turns per hour, and listening comes back by itself after a restart. Needs the Rooms app connected for the agent. It also works on joined servers; update the server to this version to use it there.
