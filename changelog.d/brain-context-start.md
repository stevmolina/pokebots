### Added

- New chats start with context from your Second Brain, for every provider: Claude, Codex, Gemini, Grok, Cursor and the others. Before the first message of a chat, and after 6 hours of quiet, an agent with a Second Brain connection gets what the brain knows about that message. If the brain takes more than 3 seconds, the chat starts without it. Turn it off in Server Settings > Agents > Brain context. It also works on joined servers; update the server to this version to use it there.
