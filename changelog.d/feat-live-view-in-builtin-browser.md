### Added

- Open a cloud computer's live view in the built-in browser. The live view card has an "Open in side
  panel" button, and "Open live view" opens the built-in browser when "Open external links in" is set
  to OpenBot on this computer's server.
- Right-click a web link in a chat and choose "Open Link in Side Panel" to open it in the built-in
  browser, on this computer's server and on a joined server.
