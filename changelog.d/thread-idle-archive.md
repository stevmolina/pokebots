### Changed

- Side threads archive by themselves after 3 days with no activity, as the Archive action does. A thread that runs a turn, has a queued message, or waits for an answer stays open. You can restore an archived thread.
- When an agent has 50 open threads, a new thread archives the idle thread with the oldest activity instead of an error. The error shows only when all 50 threads are busy.
- On a joined server, the server must also be on the new version.
