### Added

- Server Settings > Agents > Threads has two new options: "Archive idle threads" (Off, after 1, 3 or 7 days; 3 days by default) and "Archive when pull requests merge" (on by default).
- With the pull request option, an idle side thread is archived when every GitHub pull request that its messages link is merged or closed. The server reads GitHub through its GitHub connection, the gh command, or the public API for public repositories.
- The options also show on the web client and the phone app for a joined server. The server must also be on the new version.
